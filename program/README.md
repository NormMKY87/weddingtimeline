# Part-Time to Full-Time: the 90 day program

One outcome: know your quit number and have a booking system running that is on track to hit it.

Nine actions over 12 weeks. One insight and one tool per action. Lessons are 10 to 15 minutes and end with one action. Students give two to four hours a week.

The full module list, lesson by lesson, is in `context/part-time-to-full-time-context.md` section 6. The teaching calendar is in `plan/build-order.md`. Each lesson and worksheet has an Asana task with a due date set to the Friday before it is taught.

## Folder plan

Create a folder per module as the lessons are written:

```
program/module-0-start-here/
program/module-1-your-number/
program/module-2-the-enquiry-machine/
program/module-3-the-consult-and-the-close/
program/module-4-the-operating-system/
program/module-5-the-runway/
program/module-6-the-handover/
program/bonuses/
program/craft-program/
```

Each lesson gets `lesson-X.Y.md` with: insight, action, outline for the live call, worksheet spec, student questions logged during the founding intake. Worksheets sit beside their lesson.

## Founding intake rules

- Teach live once. Record nothing until May 2027.
- Log every question students ask. These shape the filmed version and the onboarding email sequence.
- Module 0 is delivered at purchase, before week 1.
- Bonuses stay locked until core actions are done.
