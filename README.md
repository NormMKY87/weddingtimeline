# Part-Time to Full-Time: Photographer Education

The numbers-based plan to go from side-hustle wedding photographer to full time without gambling the household income. This repo holds the written output for the digital products, the 90 day flagship program and the free channel. Norm (Norman Yap, Perth) is the author and the case study.

Start with `CLAUDE.md`, then `context/part-time-to-full-time-context.md`, then `plan/build-order.md`.

Task tracking lives on the Asana board: https://app.asana.com/1/1207367187505866/project/1220327362284579/board/1220327362284594

Note on the repo name: this repository was created as `weddingtimeline`. The project inside it is the photographer education business. Renaming the GitHub repo to `part-time-to-full-time` keeps the old URL redirecting.
